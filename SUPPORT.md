# Support

## Getting Help with QuestForge

- **Documentation Hub:** Start at [docs/README.md](docs/README.md) or the [Quick Start Guide](docs/quickstart.md).
- **Troubleshooting:** Check the troubleshooting table in the [Operations Runbook](docs/6-operations/runbook.md#6-troubleshooting) or run `quest doctor --fix`.
- **Bug Reports & Feature Requests:** Open an issue using our [GitHub Issue Templates](https://github.com/sweengineeringlabs/questforge/issues/new/choose).
- **Security Vulnerabilities:** Follow [SECURITY.md](SECURITY.md) to report privately via GitHub Security Advisories.

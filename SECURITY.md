# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in **QuestForge** (including credential handling, OAuth token storage, APK signing/verification, or control-plane RBAC), please **do not** open a public GitHub issue.

Instead, report it privately via GitHub Security Advisories:
https://github.com/sweengineeringlabs/questforge/security/advisories/new

Include:
- A clear description of the issue and affected component
- Steps to reproduce
- Any suggested remediation

We will acknowledge receipt promptly and coordinate a fix before public disclosure.
